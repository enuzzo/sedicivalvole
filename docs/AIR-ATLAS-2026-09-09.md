Optional schedules: `public/api/radar-flight.php` reads only `SEDICIVALVOLE_AIRLABS_API_KEY` from the server process environment. It is inactive and returns `not_configured` without a key. It resolves live flight identity by hex before requesting the schedule, rejects a mismatched aircraft, distinguishes scheduled/estimated airport-local values and bounds shared usage to 500 upstream calls/month and 20/hour (local ceilings, not a provider quota guarantee). No scheduled time is synthesized from ground speed. No `.env` is read by either radar endpoint.
