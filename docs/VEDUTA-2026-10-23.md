# Veduta — illustrated geographic travel

## Owner-selected scope

On October 23 the owner selected the first of two generated directions: an
elevated, forward-looking landscape with the horizon visible. Veduta is a
separate illustrative Visual, backed by the existing geographic runtime. It
does not replace Atlas or add its POI cards, article reader or journey panels.
The owner explicitly requested actual vehicle GPS following and optional
Tesla-shaped markers: Model 3 Highland, Model Y and basic body colours, with a
simple point as an alternative. Anime, Manga and Watercolor remain selectable
media within this one composition. After inspecting the preview, the owner
rejected the enlarged car on the street. A 12 CSS-pixel point is now the initial
preference at every zoom. Highland and Model Y remain optional, at authored
approximate metre dimensions, with white as the initial body colour.

The private selected reference is the first generated image in this chat,
`exec-92319e36-57dd-4b51-b10f-276da020c541.png`, refined with the car in
`exec-aea20e6b-76a8-4caf-87bb-9f9444648ccc.png`. These are design targets, not
runtime evidence or product backgrounds. No generated scene bitmap is shipped.

## Implementation boundary

- One lazy MapLibre 6.7.0 map, its existing same-origin worker and one shared GL
  context. The original Three.js layer owns only its geometry/materials. It
  never clears or destroys MapLibre's context and does not construct a second map.
- Existing OpenFreeMap/OpenMapTiles/OSM vector data and the already admitted
  Mapterhorn Terrarium elevation provider. Terrain exaggeration is 1.0 here;
  Fly With retains its separate 1.25 setting.
- The admitted `atlasPositionSamplesRef` is the only moving-position input.
  Observed samples interpolate with Atlas's existing bounded delay/gap rules;
  stale data hold the last position. Speed cannot manufacture a location.
- The follow camera looks a bounded distance ahead of the measured position.
  Its target is separate from the car and never written into GPS/journey data.
  Zero map padding avoids the pinned runtime's native sky/terrain horizon
  discrepancy with a padded camera. Native source bytes are unchanged.
- Original cartographic materials and small, world-anchored pigment tiles vary
  by medium. The terrain, coast and building footprints remain source-based.
  Near-field facade/roof geometry, windows and vegetation are illustrative,
  not observed architectural details or species. Trees are bounded source-area
  symbols; their deterministic grid must not change when the camera advances.
- Vehicle meshes are original, deliberately simplified optional symbols. The
  default GPS dot is a single fixed-size GL point, with a light rim, in the same
  context; it does not scale to the street or zoom. These are not manufacturer
  models, vehicle telemetry, lane
  positioning or a surveyed clearance reconstruction. DEM data omit bridge
  decks/tunnels, and the accepted GPS position can be coarser than a road width.
- Only allowlisted style/shape/colour preferences enter local storage. Neither
  positions, tile identifiers nor heights enter technical diagnostics. The two
  new diagnostic privacy booleans describe whether the feature/provider is active.
- A map retry must not restart GPS or clear the shared journey/Stats history.
  Failed tiles belong to one bounded recovery attempt: matching successful
  loads remove them; a new attempt discards obsolete coverage and tracks its
  own errors. Healthy `idle` clears only an empty current-attempt failure set.
  Failed TileJSON metadata is retried through the same source's public `setUrl`.
  Shape/colour changes made during tile loading must still take effect.
- Pending geometry/ground work schedules one repaint at its deadline. A parked
  map does not require an endless GPU loop, and hiding/removing the view cancels
  deferred work. Finite vehicle smoothing never extrapolates a GPS position.
- Network availability and GPS freshness are independent. An offline cached
  map can follow fresh GPS; only stale observations claim a held position.
- Medium changes update one map/layer in place. Zero native paint transitions
  prevent pinned MapLibre terrain textures retaining the first transition
  frame. The custom materials and map paints change as one selected medium.

GeoPoster/Places was consulted read-only while its own chat continued. Its
semantic materials and spatially stable marks informed this original renderer;
no laboratory runtime, character, pet, source fixture, generated proof or
external reference asset was copied. The heavy print-quality renderer and its
unfinished artistic/performance acceptance are separate work.

## Development and evidence

`qa-veduta.html` is a development-only, explicit synthetic-GPS fixture using the
actual application. Its public Lugano/Milan test positions are not an owner's
journey. The fixture labels itself visibly, supports pause/movement checks and
blocks automatic diagnostic delivery. It is not a production build entry and
does not add a driving Demo mode to Veduta.

The host's old Intel `node_modules` symlink was preserved outside Dropbox.
Exact lockfile dependencies were installed into a host-local ARM64 directory
under `Documents/Codex/dependencies/`, then linked into the ignored dependency
path. The failed first package extraction was retained. No lockfile version
was changed and no dependency directory was populated inside Dropbox.
For this File Provider checkout, optional `SEDICIVALVOLE_POLL_SOURCE=1` enables
1.2-second source watching while excluding dependencies, public assets, output
and dist. Credential-free commands retain `SEDICIVALVOLE_NO_LOCAL_ENV=1`.

Local model checks, rendered visual review, regression/build gates, Git
checkpoint, canonical publication, owner feedback and physical Tesla endurance
are separate evidence. The current candidate is not accepted merely because
it renders. See [design QA](../design-qa.md) for the active visual comparison and
limitations. The first runtime-derived gallery thumbnail is an original crop
of the disclosed geographic scene, not an illustration generated as a promise.

The source checkpoint `495204d` is pushed to the existing remote. Local package
`20261023-1342.495204d` passes 839 exact hashes and VERSION/HTML identity; local
chrome regression passes 16/16, text fit 14/14 and credits 189. The full package
suite passed 1,136 tests before the final dot refinement; subsequent Veduta/docs
checks pass 19. This is not a canonical deployment. The actual visible browser
was returned to Anime with the small GPS dot and marked to remain open.
