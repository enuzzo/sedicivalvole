# Community credits and release thank-you drafts

Created 2026-09-05. **Drafts only — nothing sent.** Owner: enuzzo. This is the practical outreach companion to [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md), not a substitute for license notices or the final dependency inventory.

## Important wording for release

The current original code is **source-visible, noncommercial, PolyForm-Noncommercial-1.0.0**, not an MIT/open-source app. Third-party code retains its own license or direct permission. These drafts thank open-source communities without describing all of sedicivalvole as open source or MIT. If the owner later explicitly changes the licensing policy, update LICENSE, scope, notices, package metadata and these drafts together before sending. Historical AGPL grants remain separate.

Do not call every upstream contribution MIT: Infinite Lights has a custom Codrops notice; Drivey has the documented GPL/header ambiguity; textStep relies on its GPL terms plus direct authorization. The earlier Night Glass preview notice's MIT shorthand is corrected in the appended notices.

## How to use this register

- Start with Lobo, Daniel/Codrops, Rezmason, ruucm/stone-skipper, Paweł, Björn and Zsolt, then the remaining maintainers and creators.
- Each entry gives the actual integration, a public source/contact route and a ready draft. A GitHub profile is a discovery route, not a promise that private messaging exists. Prefer a published contact address or welcomed community channel; do not file a bug merely to deliver a thank-you.
- Emails below are publicly published project contacts, not private address-book data. Email delivery and recipient preference have not been verified. No other email address is known or inferred.
- Before release, recheck the linked README credits and source revision, choose the appropriate channel, personalize the greeting, and replace the source-visible licensing sentence only if the policy truly changed. Review the recorded Drivey/textStep boundaries independently; outreach does not itself resolve licensing questions.
- Set `Sent on`, `Channel`, `Reply` and `Follow-up` after an explicitly authorized send. Maintain this file and the README credits whenever a source is added, replaced or retired.
