# Rejected Latitudes visual archive

Latitudes was removed from the active sedicivalvole product on 2026-08-28 after
the product owner rejected the direction in full. It is not a selectable visual,
is not imported by the application or QA harness, is not part of the production
build, and its old tests are not part of the active suite.

The source and historical model test remain here only as a recoverable technical
record. They must not be presented as implemented, current, pending, or approved.
A future visual direction starts from a new three-direction product decision; it
does not silently revive this renderer.
