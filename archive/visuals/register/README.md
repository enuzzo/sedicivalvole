# Rejected Register visual archive

Register was removed from the active sedicivalvole product on 2026-08-29 after
live review found the composition static, inexplicable and outside the product's
driving mood. It is not a selectable visual, is not imported by the application
or QA harness, and its historical tests are not part of the active suite.

The source and model test remain here only as a recoverable technical record.
They must not be presented as implemented, current, pending or approved. Any
replacement must begin with exactly three new visual directions and an explicit
product selection; this renderer must not be silently revived.
