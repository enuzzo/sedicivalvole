# sedicivalvole logo assets

The selected mark is the owner-approved `16 Road` direction: a central `16`
framed by two mirrored three-line roads derived from the Signal Gate language.
The mark fills a square canvas while keeping a 18–22 px optical safety margin.

## Masters

- `sedicivalvole-mark-dark.svg` — primary black-background master with a
  restrained signal glow.
- `sedicivalvole-mark-light.svg` — warm-ivory background counterpart.
- `sedicivalvole-mark-transparent.svg` — true-alpha master without glow.

The `16` is not live text. It is the path outline of the locally packaged
Orbitron variable font at weight 750, so the mark remains byte-stable and does
not depend on an installed font. All masters use a `512 × 512` viewBox and the
product's restrained 6 px outer corner language.

Generated PNG and favicon derivatives are reproducible outputs of
`scripts/render-logo-assets.py`; the SVG files remain the editable sources of
truth.
